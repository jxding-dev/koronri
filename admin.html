여기서 가격을 수정하고 저장하면 사이트에 자동으로 반영됩니다. (반영까지 약 1~2분 소요)

최초 1회 설정 — 저장 권한을 위해 GitHub 토큰이 필요합니다.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: jxding-dev/commission 선택
  3. Permissions → Repository → Contents: Read and write
  4. 생성된 토큰을 아래에 붙여넣고 저장하세요.

토큰은 이 브라우저에만 저장되며 GitHub 외 어디에도 전송되지 않습니다. 공용 PC에서는 사용 후 토큰 지우기를 눌러주세요.
